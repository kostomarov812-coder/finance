# Умный финансовый планировщик

Личный планировщик бюджета: дневная норма, доходы, долги, регулярные платежи, аналитика трат и ассистент.

Открыть: https://kostomarov812-coder.github.io/finance/

Данные хранятся только в браузере телефона — в репозиторий ничего не попадает. Делайте «Экспорт JSON» в настройках.
